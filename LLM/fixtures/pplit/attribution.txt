It is prompt/response pairs marked up with <|@PROMPT@|> and
<|@RESPONSE@|>. It is vendored rather than referenced so that --pplit
works in a clean checkout instead of needing a second repository, the
same reason the Tatoeba audio beside it is vendored.

Re-fetch it from the URL above rather than editing it here: a local edit
would silently change every perplexity this repo has ever reported.
