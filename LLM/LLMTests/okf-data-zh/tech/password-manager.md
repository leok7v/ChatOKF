一个保险库，跟Dana共用，用一句别人都不知道的长口令解锁。

它解决的问题：四十个网站用同一个密码，还有我们俩谁也进不了对方开的账号。

共享的条目：[路由器管理](/tech/router-settings.md)、[宽带账号](/tech/isp-plan.md)、
[流媒体订阅](/watch/subscriptions.md)、水电气，
还有[积分和里程](/travel/points-and-miles.md)里的航空公司会员。

恢复才是难的部分。应急包打印出来放在防火箱里，
因为一个你自己进不去的密码管理器比没有还糟。

两步验证先给邮箱开，别的都往后排。
