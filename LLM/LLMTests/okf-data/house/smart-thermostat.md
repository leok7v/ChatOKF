title: The smart thermostat
description: Scheduling and remote control are the real value; the
  learning feature mostly needed turning off.
tags: [house, hvac, smart-home, energy]
---

Installed on the existing 24-volt wiring. Needed a C wire, which this house
had. Many older houses do not, and that is the whole install problem.

What is actually worth it: a real schedule, remote change from the phone
when plans change, and the filter reminder that keeps
[the furnace filter](/house/furnace-filter.md) honest.

What is not: the learning behavior, which kept deciding we were away
because we work in a back room. Turned it off and set a schedule by hand.

It is on [the home network](/tech/wifi-mesh.md) and it is one of the
devices that argued for a separate network for gadgets. See
[the IoT network](/tech/iot-network.md).
