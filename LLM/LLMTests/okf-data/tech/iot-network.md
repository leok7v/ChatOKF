title: A separate network for the gadgets
description: Smart bulbs, the doorbell, the TVs and the thermostat live
  on their own SSID so they cannot see the laptops.
tags: [tech, network, security, smart-home]
---

Second SSID, guest-style isolation on, everything cheap and internet-
connected lives on it: [bulbs](/tech/smart-bulbs.md),
[the doorbell](/tech/doorbell-camera.md),
[the robot vacuum](/tech/robot-vacuum.md),
[the thermostat](/house/smart-thermostat.md),
[the TV](/tech/smart-tv-livingroom.md).

The reasoning is not paranoia, it is that these devices get security
updates for about two years and then never again, and they sit on the
network for a decade.

The annoyance: casting from a phone to the TV needs both on the same
network, so the phones join the gadget network when casting. There is a
setting for cross-SSID discovery and it works about half the time.

Laptops, phones and [the backup box](/tech/nas-backup.md) stay on the main
network.
