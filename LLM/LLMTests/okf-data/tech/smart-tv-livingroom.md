65-inch 4K, 2021, wall mounted over the fireplace, which was a mistake for
viewing angle and is not getting undone.

The built-in smart platform is slow, shows ads on the home screen, and
stopped getting app updates in 2024. So it is used as a monitor:
[the Apple TV](/tech/appletv.md) is the only input anyone touches.

Wired to [ethernet](/tech/ethernet-runs.md), wifi disabled on the set
itself.

Settings that mattered: motion smoothing off, "vivid" picture mode off,
and the automatic content recognition turned off in a menu three levels
deep. See [calibration](/tech/tv-calibration.md).

It is on [the gadget network](/tech/iot-network.md).
